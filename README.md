# FreeCut

Browser-based video editor (PWA) — React + TypeScript + Vite. Goal: a free, offline-capable alternative to CapCut. **v1.2.3 — Phase 1a: import your own videos, photos and audio** (+ iPhone thumbnail fix, real filmstrips, full-quality player) (real thumbnails, library, add to timeline; playback arrives in Phase 1b). See `Roadmap.md`.

## Run locally

```bash
npm ci                # exact versions from package-lock.json
npm run dev           # dev server
npm run verify        # typecheck → lint → tests → production build
npm run preview       # serve the production build (use this to test offline/PWA)
npm run e2e           # Playwright; first: npx playwright install chromium webkit
```
Node ≥ 18.18. See `Handover.md §2` for every script.

## Deploy to Vercel

**Option A — Git (recommended)**
1. Push this folder to a GitHub/GitLab/Bitbucket repo.
2. In Vercel: *Add New → Project*, import the repo.
3. Vercel auto-detects Vite (build: `npm run build`, output: `dist`). Click *Deploy*.

**Option B — CLI**
```bash
npm i -g vercel
vercel        # preview deploy
vercel --prod # production deploy
```

## Install & offline (PWA)
- After the first visit the whole app is cached by a service worker, so it opens with no connection.
- **Chrome / Edge / Android:** use the install icon in the address bar (or menu → *Install FreeCut*).
- **iPhone / iPad:** Safari → Share → *Add to Home Screen*.
- The service worker and manifest are only generated by `npm run build` (not `npm run dev`). To test locally: `npm run build && npm run preview`.
- Icons live in `public/` (`pwa-192x192.png`, `pwa-512x512.png`, `pwa-maskable-512x512.png`, `apple-touch-icon.png`).

## Notes
- **Where things are:** `src/app` (shell, boot, routing), `src/model` (project model), `src/store` (state, undo/redo), `src/storage` (IndexedDB autosave), `src/media` (import pipeline, media store), `src/editor` (panels, timelines), `src/home` (startup screen + hero art), `src/ui` (shared controls), `src/styles` (CSS). Map and explanations: `Handover.md §3`, `how_it_works.md §1`.
- **Product name:** `src/app/brand.ts` (`BRAND_NAME`, `BRAND_ACCENT`); also `<title>` / meta tags in `index.html` and `name` / `short_name` in `vite.config.ts`.
- **Project data & saving:** the project is stored in the browser's IndexedDB (database `freecut`), autosaved ~0.5 s after each edit. Home → *Reset demo project* (two taps) restores the sample. Details: `how_it_works.md §4–5`.
- **Home content:** placeholders `TOOLS` and `TEMPLATES` at the top of `src/home/Home.tsx` (they open the editor until Phase 9). The hero scene + headline rotate on every app open and never repeat the last pick (`src/home/heroPick.ts`, remembered in `localStorage`); add headlines to `HEADLINES` there, add scenes in `src/home/HeroScenes.tsx` (register in `SCENE_ART`, append to `SCENES`, animate in `src/styles/scenes.css`). Recipe: `Knowledge_Contribution.md A7`.
- **Screen transitions:** push/pop on phones, zoom + fade on desktop, quick fade under reduced motion (`src/app/useScreenRouter.ts`, `src/styles/transitions.css`); `TRANSITION_MS` must stay slightly longer than the longest animation there.
- `lucide-react` is pinned to the `0.383.x` line to match the icons used.
